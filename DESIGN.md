# TaskFlow Design System

## 1. Visual Style
- **Mood:** Minimal, clean, swiss, functional, neutral, professional.
- **Framework:** Ant Design inspired.
- **Grid:** 8px grid system.

## 2. Color Palette
- **Primary:** #E96A2C (Premium Orange)
- **Background:** #FAFAFA
- **Text:** #0F172A

## 3. Typography
- **Headings:** Plus Jakarta Sans
- **Body:** Inter
- **Weights:** 300, 400, 500, 600, 700, 800

## 4. Components
- **Buttons:** Rounded-2xl, strong weights, shadow-xl (orange-500/30).
- **Cards:** Rounded-[3rem], deep subtle shadow (shadow-2xl), 24px blur glassmorphism.
- **Forms:** Clean labels, bg-slate-50 focus:bg-white focus:ring-4.

## 5. Layout Pattern
- **Pattern:** Enterprise Gateway.
- **Floating Navigation:** Fixed or floating header with consistent spacing.

## 6. Design System Notes for Stitch Generation (REQUIRED)
Use the following block in all Stitch prompts to ensure consistency:

**DESIGN SYSTEM:**
- **Primary Color:** #E96A2C (Premium Orange)
- **Typography:** Plus Jakarta Sans (Headings), Inter (Body)
- **Components:** Premium, Rounded-3xl, Custom glassmorphism
- **Visual Depth:** 24px backdrop blur and soft diffuse shadows
- **Spacing:** Modern, breathable layout
- **Aesthetic:** High-end SaaS, Luxury productivity tool
